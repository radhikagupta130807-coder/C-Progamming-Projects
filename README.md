# Film Rating Analyzer

A simple and interactive **C programming project** designed to analyze and categorize movie ratings based on user input.

## 📌 Features
*  **User Input:** Accepts the movie name and its rating.
*  **Rating Validation:** Ensures the input rating falls within the standard '0.0 to 5.0' range.
*  **Smart Categorization:** Uses conditional logic to classify movies into categories like *Hit, Flop, Average, or Blockbuster*(based on your specific code logic).

## 🛠️ Tech Stack
* **Language:** C Programming
* **Core Concepts Used:** Conditional Statements ('if-else'), Data Types, Standard Input/Output ('stdio.h').

##💻 How to Run
1. Copy the code from 'Film_Rating_Analyzer.c'.
2. Paste it into any online C compiler (like OnlineGDB) or a local IDE (like VS Code).
3. Compile and run the program.
